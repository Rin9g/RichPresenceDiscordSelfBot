### Streaming Rich Presence Selfbot

```env
STREAM_URL=
STATUS_MESSAGES=
DISCORD_TOKEN=
BUTTON_DISCORD=
APPLICATION_ID=
PRESENCE_STATE=
```

*I removed one button, and `PRESENCE_STATE` is optional.*


###Example:
```STREAM_URL=https://www.twitch.tv/killerqueen_lol
STATUS_MESSAGES=𝔤𝔭𝔥
DISCORD_TOKEN=
BUTTON_DISCORD=https://www.instagram.com/raininginhe4rt/
APPLICATION_ID=1534085805868322907 #for the rpc image, make a discord legal bot at https://discord.com/developers/applications and set the bot profile image
PRESENCE_STATE=ntt ntt ntt ntt ntt ntt ntt ntt ntt ntt ntt ntt ntt ntt ntt
```
